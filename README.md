# UAEC 2026 - Programming

Welcome to the UAEC 2026 Programming Category repo!

This repo contains the resources and datasets requried to complete the programming challenge.

## **Dataset Useage and Evaluation**
The dataset provided is intended for competitors to develop, test and validate their programs before the judging period. 

During the judging portion, team will receive a separate dataset to evaulate how well your program identifies and responds to battery conditions and edge cases. 

**IMPORTANT**: Competitors should ensure their program can process the judging dataset as a CSV file. 

## **Getting Started**

Click the green _Use this template button_ > _Create a new repository_.

Ensure your repository is private during the working period so other teams cannot view your code.

Once you make your copy, ensure you update this README for your project. As well, **make your repo public prior to submitting** to ensure judges and organizers can access your code.

Good luck!
